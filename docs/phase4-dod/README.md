# Phase 4 definition-of-done transcripts

These files are generated by:

```bash
python scripts/phase4_definition_of_done.py
```

The default run scripts **model decisions** (a fixed planner and scripted
agents) while exercising the real Phase 4 runtime: task graph, tool registry,
approval protocol, change tracker, validation discovery, subprocess execution,
failure parsing and correction loop. Each transcript header says
`scripted model, real runtime` so the provenance is unambiguous.

| Demo | Transcript | Outcome |
|---|---|---|
| A — Task-management app | [a-task-management-app.md](a-task-management-app.md) | 3 files created; `python -m pytest -q` passed; 1/1 task verified |
| B — Dark-mode toggle | [b-dark-mode-toggle.md](b-dark-mode-toggle.md) | 2 files modified; `node --check` passed; status says "syntax check only; no tests or build found" |
| C — Find and fix a bug | [c-find-and-fix-a-bug.md](c-find-and-fix-a-bug.md) | first validation `FAILED`; 1 correction; second validation `PASSED`; task verified |
| D — Bounded correction | [d-bounded-correction.md](d-bounded-correction.md) | 2 corrections used; third validation still failed; task `FAILED`; run `failed`; 0 verified |

Every transcript includes the captured event stream, the approval decisions and
the checks the harness performed. The unattended harness approves file writes
and only accepts validation-shaped commands; this is a demo convenience, not a
security boundary.

## Real-model attempt

A real-model run was attempted once with the locally installed `qwen3:8b`:

```bash
python scripts/phase4_definition_of_done.py --real --model qwen3:8b --only a
```

The command did not complete within the 10-minute foreground window, continued
in the background, and exited with code 1. Its final output was:

```text
== demo A: Task-management app ==
   FAILED: task_app.py exists
   (real-model demos depend on the local model and may be skipped)
```

The run did not produce the expected task-management file, so demo A is **not**
claimed as a real-model pass. Per the resource guidance, the expensive real-model
test was not restarted. The authoritative A–D evidence is the deterministic
transcript set above; the real-model path remains available for a machine with
more time or memory budget.
